# CXR local adaptation reproducibility release

Source_Data contains the frozen aggregate results used by the manuscript and current Figures 1–4. Code contains numerical analyses, fixed training settings, focused tests, a public-data-independent aggregate verification command and figure reproduction from the aggregate snapshot. See Code/README.md for the distinction between aggregate reconstruction and rerunning models or image-level analyses.

The study is retrospective and exploratory for local adaptation. VinDr image identifiers establish image separation, while independent patient counts and complete historical test exposure remain unverified. The source models, repeated fitting seeds and overlapping calibration samples are not independent clinical cohorts.
